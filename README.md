# More Than Wombat

**Direkt spielen:** [More Than Wombat auf GitHub Pages](https://emfau88.github.io/MoreThanWombat/)

Ein comic-hafter 2.5D-Arcade-Brawler mit kurzen Sessions, klaren Trefferreaktionen und charakterstarken Spezialangriffen.

## Entwicklung

Der aktuelle Arbeitsbereich ist der [Gameplay- und Wave-Completion-Plan](docs/31_GAMEPLAY_AND_WAVE_COMPLETION_PLAN.md). G1–G4 sind implementiert und technisch geprüft: Der `Junkyard Run` besitzt sieben Encounter, rollenbasierten Gruppendruck, Guard/Evade sowie Knockdown und geschütztes Wake-up. Als Nächstes folgt die gemeinsame manuelle Spielgefühl- und Balanceabnahme, danach G5. [G4-Prüfbericht](docs/qa/g4-runtime-2026-09-08/README.md).
