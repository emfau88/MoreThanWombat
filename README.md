# More Than Wombat

**Direkt spielen:** [More Than Wombat auf GitHub Pages](https://emfau88.github.io/MoreThanWombat/)

Ein comic-hafter 2.5D-Arcade-Brawler mit kurzen Sessions, klaren Trefferreaktionen und charakterstarken Spezialangriffen.

## Entwicklung

Der aktuelle Arbeitsbereich ist der [Gameplay- und Wave-Completion-Plan](docs/31_GAMEPLAY_AND_WAVE_COMPLETION_PLAN.md). G1–G7 sind implementiert und technisch geprüft: Der `Junkyard Run` besitzt sieben Encounter, rollenbasierten Gruppendruck, Guard/Evade, Knockdown, Run/Dash-Angriffe, Stage-Interaktionen, Midboss und einen zweiphasigen Endboss. Der vorgezogene UI-Schritt liefert professionelle Touch-Controls, gefüllte Fighter-Portraits, korrekt eingefasste Ressourcenbalken und kaschierte Zonenübergänge. Als Nächstes folgt G8 mit Ressourcen- und Gesamtbalance; die gemeinsame manuelle Spielgefühl-, Balance- und Realgeräteabnahme bleibt offen. [G7-Prüfbericht](docs/qa/g7-runtime-2026-09-09/README.md).
