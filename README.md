# More Than Wombat

**Direkt spielen:** [More Than Wombat auf GitHub Pages](https://emfau88.github.io/MoreThanWombat/)

Ein comic-hafter 2.5D-Arcade-Brawler mit kurzen Sessions, klaren Trefferreaktionen und charakterstarken Spezialangriffen.

## Entwicklung

Der aktuelle Arbeitsbereich ist der [Gameplay- und Wave-Completion-Plan](docs/31_GAMEPLAY_AND_WAVE_COMPLETION_PLAN.md). G1–G7 sind implementiert und technisch geprüft: Der `Junkyard Run` besitzt sieben Encounter, rollenbasierten Gruppendruck, Guard/Evade, Knockdown, Run/Dash-Angriffe, Stage-Interaktionen, Midboss und einen zweiphasigen Endboss. Beim vorgezogenen Battle-UI-Neuaufbau sind UI-R0 bis UI-R4 abgeschlossen: Layoutvertrag, adaptive Touch-Geometrie, professionelle Action-Assets, modulares HUD, sieben echte Charakterporträts sowie eigene Normal-Wave-/Midboss-/Boss-Semantik. Als Nächstes folgt UI-R5 für Integration und Realgeräteabnahme, anschließend G8. Die gemeinsame manuelle Spielgefühl-, Balance- und Realgeräteabnahme bleibt offen.
