# 06 — MVP Scope

## MVP Name

**More Than Wombat — Combat Sandbox MVP**

## Purpose

Prove that the game can feel good as a mobile-first 2D brawler before building content.

## Included

### Player

- One playable Wombat.
- Four-direction movement.
- Left/right facing.
- Normal attack.
- Special attack or placeholder special.
- Health.
- Hit reaction.
- Knockdown optional after HP reaches zero.

### Enemy

- One Angry Pigeon enemy.
- Basic AI.
- Health.
- Basic attack.
- Hit reaction.
- Death/removal.

### Arena

- One rectangular arena.
- Pseudo-depth movement.
- Simple bounds.
- Depth sorting.

### Combat

- Hitbox/hurtbox separation.
- Attack timing.
- Damage.
- Knockback.
- Hitstun.
- Basic invulnerability window optional.

### Input

- Desktop keyboard for development.
- Mobile virtual joystick.
- Attack button.
- Special button.

### UI

- Player HP.
- Enemy HP or simple enemy count.
- Debug info toggle.

## Excluded

Do not include in MVP:

- Character select.
- Multiple player characters.
- Multiple levels.
- Story.
- Shop.
- Save/load.
- Unlocks.
- World map.
- Online multiplayer.
- Local multiplayer.
- Ads.
- Analytics.
- Complex VFX.
- Complex animation blending.
- Advanced physics.
- Pathfinding.

## MVP Completion Definition

The MVP is complete when:

- The game can be opened on a phone.
- The player can move and attack.
- The enemy can attack.
- Both sides can take damage.
- Combat has visible hit reactions.
- There is a win/lose condition.
- Code remains modular.
- No major input or state bugs are present.
