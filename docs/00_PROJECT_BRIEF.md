# 00 — Project Brief

## Working Title

**More Than Wombat**

## Genre

Mobile-first 2D pseudo-depth arena brawler / beat 'em up.

## Reference Direction

The gameplay direction is inspired by classic 2D brawlers with pseudo-depth movement, especially the general feel of Little Fighter 2:

- Side-view characters.
- Movement on a horizontal arena plane.
- Up/down movement used as depth movement.
- Multiple characters on screen.
- Fast attacks, knockback, and simple readable combat.

This project must not copy protected characters, assets, names, exact animations, sounds, UI, or proprietary content from any reference game.

## Product Intent

Create a funny, readable, lightweight HTML5 brawler that runs well on mobile browsers and can later be wrapped as an Android app if desired.

The game should feel silly but mechanically clean.

## Tone

Cartoon animal chaos.

Examples:

- A wombat body-slamming pigeons.
- Angry birds, raccoons, frogs, hedgehogs, kangaroos, and other absurd opponents.
- Slapstick hits.
- Exaggerated but readable effects.
- Short sessions.

## First Milestone

A playable combat sandbox with:

- One player character: Wombat.
- One enemy: Angry Pigeon.
- One arena.
- Four-direction movement.
- Facing left/right.
- One normal attack.
- One special attack.
- Hitbox/hurtbox system.
- Health.
- Knockback.
- Basic enemy AI.
- Mobile touch controls.
- Desktop debug controls.

## Critical Warning

The project fails if the agent starts by building menus, shops, unlocks, story, character select, world map, or asset polish before the combat core works.

The first target is not beauty. The first target is a correct combat loop.
